# Conexão JARVIS

O app de celular do assistente Jarvis (projeto pessoal). Ele só funciona pareado com o PC servidor:
abra a aba **CELULAR** no Jarvis do PC, ligue o **acesso remoto** e escaneie o QR code.

Este repositório contém apenas os arquivos estáticos do app. Nenhuma chave, endereço ou token fica aqui.
